# 输入中的技术博客

A minimal Hexo-based technical blog using the Butterfly theme.

## Commands

```bash
npm install
npm run build
npm run server
npm run clean
```

## Writing

Create a new post with:

```bash
npx hexo new post "post-title"
```

Posts are stored in `source/_posts/`.

Writing conventions are maintained in [docs/blog-writing-guide.md](docs/blog-writing-guide.md).
